Codes d'activité

Chaque code alimente ou décompte un compteur de 0,5 j par demi-journée : un code qui alimente compte tous les jours, un code qui décompte seulement les jours ouvrés. Chaque code a sa couleur. Un code utilisé ne peut plus changer d'effet ni de compteur, ni être supprimé : archivez-le pour le retirer des listes de saisie.
